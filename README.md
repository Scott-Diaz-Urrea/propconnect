# PropConnect

Maqueta de diseño de un marketplace inmobiliario para Chile: propiedades verificadas, agenda de visitas con horarios reales y carpeta de arriendo reutilizable.

**Demo:** https://scott-diaz-urrea.github.io/propconnect/

> Es una demo de diseño. Los datos, agentes, precios y verificaciones son ficticios y no hay servidor: todo vive en el navegador.

## Cambiar las fotos

Las fotos están en `fotos/`, una carpeta por propiedad.

- **Cambiar una foto:** reemplaza el archivo con el mismo nombre.
- **Agregar o quitar fotos:** edita `fotos/fotos.js`. La primera foto de cada lista es la portada.

## Créditos

Fotos de [Unsplash](https://unsplash.com), solo ilustrativas: no corresponden a propiedades reales.
